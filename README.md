# Привет! Я Богдан 👋

Разрабатываю веб-приложения, игровые инструменты и сервисы для обучения. Люблю превращать идеи в работающие продукты — от интерфейса и API до базы данных.

## Избранные проекты

### [LoreForge — Campaign OS для настольных RPG](https://github.com/Zerro15/LoreForge)
Кампании, сцены, персонажи, NPC, локации, чат, кубики и секреты мастера в одном пространстве. Подключаемые правила помогают вести разные игровые миры.
**Стек:** TypeScript, Next.js, Fastify, PostgreSQL, Docker.

### [Mashenin — мессенджер](https://github.com/Zerro15/Mashenin)
Самостоятельно размещаемый чат с комнатами и текстовыми сообщениями.
**Стек:** Next.js, Fastify, PostgreSQL, Redis.

### [ClassFlow — помощник для репетиторов](https://github.com/Zerro15/Class)
MVP для работы с учениками, занятиями, оплатами и домашними заданиями.
**Стек:** FastAPI, Next.js, PostgreSQL.
